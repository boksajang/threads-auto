Threads Auto · Chrome Extension

개인정보처리방침

이 방침은 Chrome 확장 프로그램 Threads Auto - 쿠팡 상품 수집기가 처리하는 정보와 그 이용 방법을 설명합니다.

시행일: 2026년 8월 30일 적용 버전: 0.1.2 이상

1. 핵심 안내

확장 프로그램은 사용자가 Threads Auto에서 직접 요청한 쿠팡 상품의 웹사이트 콘텐츠만 처리합니다. 개발자가 운영하는 외부 수집 서버로 데이터를 전송하거나, 광고·추적·판매 목적으로 이용하지 않습니다.

2. 처리하는 정보

사용자가 Threads Auto에 상품 수집을 요청한 경우에만 다음 정보를 처리합니다.

  • 상품 식별값(productId, itemId)
  • 상품명 원문
  • 상품 갤러리 이미지 주소(최대 20개)
  • 화면에 공개된 후기 본문, 상품 옵션 및 평점(최대 8건)
  • 수집 완료 시각

처리하지 않는 정보

  • 후기 작성자의 이름·닉네임·아이디 등 작성자 표시정보
  • 사용자의 웹 방문 기록 또는 방문 페이지 목록
  • 쿠키, 로그인 정보, 비밀번호 및 인증정보
  • 결제정보, 금융정보, 위치정보 및 연락처
  • 키 입력, 마우스 움직임 및 일반적인 브라우저 활동

3. 처리 목적과 작동 방식

처리한 정보는 Threads Auto에서 상품 자료를 확인하고, 사용자가 요청한 게시물 초안을 생성하는 목적으로만 사용합니다.

사용자가 Threads Auto에서 상품 수집을 요청합니다.
Threads Auto가 상품 식별값을 확장 프로그램에 전달합니다.
확장 프로그램이 일치하는 쿠팡 상품 페이지의 공개 콘텐츠를 확인합니다.
결과를 같은 컴퓨터의 Threads Auto로 반환합니다.

4. 전송, 저장 및 보유 기간

  • 확장 프로그램은 Chrome Native Messaging을 사용해 같은 컴퓨터에 설치된 Threads Auto와 통신합니다.
  • 확장 프로그램 자체는 수집 결과를 Chrome 저장소에 지속적으로 보관하지 않습니다.
  • Threads Auto는 사용자가 확인할 수 있도록 수집 결과, 생성된 초안 및 처리 이력을 로컬 데이터베이스에 저장할 수 있습니다.
  • 로컬에 저장된 정보는 사용자가 Threads Auto에서 해당 자료 또는 계정을 삭제할 때까지 보관될 수 있습니다.

사용자가 Threads Auto에서 AI를 이용한 자료 분석이나 본문 생성을 직접 요청한 경우, 필요한 웹사이트 콘텐츠가 사용자가 선택하고 승인한 AI 실행 환경에서 처리될 수 있습니다. 확장 프로그램은 개발자가 운영하는 별도의 서버로 해당 정보를 직접 전송하지 않습니다.

5. 제3자 제공 및 판매

  • 사용자 데이터를 판매하지 않습니다.
  • 개인 맞춤 광고, 리타게팅 광고 또는 사용자 추적에 사용하지 않습니다.
  • 확장 프로그램의 전용 목적과 관계없는 용도로 사용하거나 전송하지 않습니다.
  • 신용도 판단, 대출 또는 금융 심사에 사용하지 않습니다.

사용자가 요청한 기능을 수행하기 위해 사용자가 선택한 AI 서비스가 이용되는 경우에는 해당 서비스의 이용약관과 개인정보처리방침이 함께 적용될 수 있습니다.
